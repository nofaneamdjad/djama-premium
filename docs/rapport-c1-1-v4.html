02 Axe 1 — 6 PDFs reels generes

Route serveur (DEV ONLY)

// src/app/api/test-pdf/route.ts
export async function POST(req: NextRequest) {
  if (process.env.NODE_ENV === "production") return NextResponse.json({error: "Not available"}, {status: 403});
  const data = await req.json();
  const buffer = await generatePdfBuffer(data); // jsPDF Node.js side
  return new NextResponse(buffer, { headers: {"Content-Type": "application/pdf"} });
}

Tests stress (qualite de rendu)

Longues descriptions OK

200+ caracteres par article - coupure propre sans chevauchement entre pages.

Article bas de page OK

Article trop grand en bas de page - saut automatique vers page suivante, pas de coupure interne.

Remises globales OK

Remise de 15% appliquee - ligne de remise affichee dans le recapitulatif, calcul correct.

Multi-taux TVA OK

Articles avec TVA 0%, 5.5%, 10%, 20% - chaque taux affiche separement dans le recapitulatif.

Conditions de paiement OK

Texte long de conditions (500 caracteres) - rendu dans le pied de page sans debordement.

Mentions legales longues OK

Mentions legales de 800 caracteres - rendu sur nouvelle page si necessaire, lisible.

Apercu en temps reel OK

Ajout d'articles - apercu se met a jour avec le bon nombre de pages (pagination DOM A4).

Coherence PDF/apercu OK

Pages apercu (DOM) = pages PDF (jsPDF) pour 5, 50, 100 articles.

Architecture de pagination intelligente V3

// Coupure aux frontieres d'articles - page.tsx
// ResizeObserver + data-invoice-row markers
const rows = container.querySelectorAll('[data-invoice-row]');
let pageEnd = headerHeight + pageContentHeight; // ~179px + 663px = 842px (A4 naturel)
rows.forEach(row => {
  const rowBottom = row.offsetTop + row.offsetHeight;
  if (rowBottom > pageEnd) {
    insertPageBreak(); // coupure propre a la frontiere d'articles
    pageEnd += pageContentHeight;
  }
});
